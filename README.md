# 수업공유

수업 중에 **링크·텍스트·파일**을 학생들에게 바로 전달하는 작은 웹 서비스입니다.

선생님이 수업방을 만들면 숫자 6자리 주소와 QR 코드가 생기고, 학생은 그 주소로 들어오기만 하면 됩니다.
선생님이 공유한 내용은 학생 화면에 **새로 고침 없이** 나타납니다. 학생은 회원 가입도, 앱 설치도 필요 없습니다.

두 가지 방식으로 쓸 수 있습니다.

| | Vercel에 올리기 | 직접 서버 실행 |
| --- | --- | --- |
| 필요한 것 | Vercel 계정 (+ 무료 Redis·Blob 저장소 연결) | Node.js가 깔린 컴퓨터나 서버 |
| 공유 내용이 보이기까지 | 보통 2~5초 | 즉시 (실시간 연결) |
| 파일 저장 | Vercel Blob | 서버의 디스크 |
| 어울리는 경우 | 서버 없이 인터넷 주소로 쓰고 싶을 때 | 교실 내부망, 학교 서버, 큰 파일 |

- [Vercel에 올려서 쓰기](#vercel에-올려서-쓰기)
- [직접 서버로 실행하기](#직접-서버로-실행하기)

## 할 수 있는 일

**선생님**

- 링크나 글을 붙여넣고 Enter → 학생 화면에 표시
  - `naver.com`, `forms.gle/abc` 처럼 주소만 적어도 누를 수 있는 링크가 됩니다.
  - "코드로 표시"를 켜면 들여쓰기가 그대로 보이는 고정폭 글꼴로 전달됩니다 (소스 코드, 명령어).
- 파일은 끌어다 놓거나, 화면 캡처를 `Ctrl+V`로 붙여넣거나, "파일 추가"로 고른 뒤 **공유**를 눌러 전송
  - 실수로 엉뚱한 파일을 보내지 않도록, 담은 목록을 확인하고 나서 보내는 방식입니다.
- "크게 보기": 교실 화면에 QR 코드와 주소를 크게 띄우기 (인쇄해서 교실에 붙여 둘 수도 있습니다)
- 지금 접속한 학생 수 확인, 항목 하나씩 또는 한꺼번에 지우기, 수업방 이름 바꾸기
- "선생님용 링크 복사": 다른 기기(교실 컴퓨터, 휴대폰)에서도 같은 수업방을 관리

**학생**

- 주소(또는 QR 코드, 또는 처음 화면에서 숫자 6자리)로 접속
- 링크는 **열기**, 글은 **복사**, 파일은 **다운로드** — 이미지·PDF·영상·텍스트는 **바로 열기**도 가능
- 한글 파일 이름이 깨지지 않습니다 (macOS에서 올린 파일의 자소 분리 포함).

## Vercel에 올려서 쓰기

Vercel은 요청이 올 때만 잠깐 실행되는 방식이라, 수업방 내용을 기억해 둘 곳과 파일을 둘 곳이 따로 필요합니다.
그래서 **Redis**(수업방·공유 항목)와 **Blob 저장소**(파일)를 프로젝트에 연결합니다. 둘 다 Vercel 대시보드에서 만들 수 있고 무료 구간이 있습니다.

> **알려 둘 점** — Vercel용 구성은 Redis와 Blob을 흉내 낸 환경에서 자동 테스트와 브라우저 검증을 마쳤지만,
> 실제 Vercel에 배포해서 확인하지는 못했습니다. 올린 뒤 아래 [배포 후 확인할 것](#배포-후-확인할-것)을 한 번 따라 해 주세요.

### 순서

**1. 프로젝트 올리기** — 둘 중 편한 방법으로

- GitHub에 이 폴더를 저장소로 올린 뒤, Vercel 대시보드에서 그 저장소를 가져옵니다 (Framework Preset은 `Other`).
- 또는 이 폴더에서 Vercel CLI로 바로 올립니다.

  ```bash
  npx vercel
  ```

  ```bash
  npx vercel --prod
  ```

빌드 방법과 주소 규칙은 `vercel.json`에 들어 있어 따로 설정할 것이 없습니다.

**2. Redis 연결** — 프로젝트의 **Storage** 탭에서 Redis(마켓플레이스의 **Upstash**)를 만들어 이 프로젝트에 연결합니다.
연결하면 접속 정보가 환경 변수로 자동 등록됩니다 (`KV_REST_API_URL`·`KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN` — 어느 쪽이든 인식합니다).

**3. Blob 저장소 연결** — 같은 **Storage** 탭에서 Blob 저장소를 **공개(Public)** 로 만들어 연결합니다.
연결하면 `BLOB_STORE_ID`가 자동 등록됩니다 (예전에 만든 저장소는 `BLOB_READ_WRITE_TOKEN` — 어느 쪽이든 인식합니다).
`BLOB_STORE_ID` 방식은 비밀 값 없이, Vercel이 함수에 건네주는 신원 토큰(OIDC)으로 저장소에 접속합니다.

**4. 환경 변수 추가** — **Settings → Environment Variables**

| 이름 | 값 |
| --- | --- |
| `TEACHER_PASSWORD` | 수업방을 만들 때 물어볼 비밀번호. **꼭 지정하세요.** 없으면 주소를 아는 누구나 수업방을 만들고 파일을 올릴 수 있습니다. |
| `CRON_SECRET` | 아무도 모르는 긴 문자열. 매일 한 번 도는 파일 정리 작업을 Vercel만 실행할 수 있게 합니다. 없으면 정리 작업이 돌지 않습니다. |
| `SITE_NAME` | (선택) 화면에 표시할 이름. 기본값 `수업공유` |

**5. 다시 배포** — 저장소 연결과 환경 변수는 **그 뒤에 새로 만든 배포부터** 적용됩니다. 이미 떠 있는 배포에는 반영되지 않습니다.
Deployments에서 맨 위 배포의 ⋯ → **Redeploy** 를 누르거나, 저장소에 새 커밋을 올리거나, `npx vercel --prod`를 다시 실행하세요.

이제 `https://<프로젝트 이름>.vercel.app` 으로 접속해 수업방을 만들면 됩니다.

### 배포 후 확인할 것

1. 첫 화면에서 수업방이 만들어지는지. "서버 설정이 아직 끝나지 않았습니다"가 보이면 그 옆에 빠진 저장소가 함께 표시됩니다.
   2·3번 연결 뒤에 **다시 배포했는지** 확인하세요. (`https://<주소>/api/config` 를 열면 그 배포가 받은 저장소 관련 환경 변수의 이름이 `seen`에 나옵니다)
2. 다른 기기(휴대폰)로 접속한 뒤 글을 공유했을 때 5초 안에 보이는지.
3. 파일 올리기 → 휴대폰에서 다운로드 → 선생님 화면에서 삭제.
4. 하루 뒤 Vercel의 Cron Jobs / Logs에서 `/api/cron/cleanup`이 성공(200)으로 기록됐는지.

문제가 생기면 Vercel의 **Logs**에 찍힌 오류 문구가 원인을 찾는 데 가장 도움이 됩니다.

### Vercel에서 달라지는 점

- **반영 시간**: 학생 화면이 3초마다 "바뀐 것 있나요?"를 묻는 방식이라, 공유한 내용이 보이기까지 보통 2~5초 걸립니다.
  이 물음의 답은 Vercel의 CDN이 2초 동안 보관해 같은 수업방 학생들에게 나눠 주므로, 학생 수가 많아도 함수 실행 횟수는 늘지 않습니다.
- **요청 수**: 그래도 요청 자체는 학생 수만큼 생깁니다. 화면을 보고 있는 학생 한 명이 3초에 한 번(가려진 탭은 12초에 한 번,
  한동안 변화가 없으면 6~9초에 한 번) 꼴입니다. 학생 30명이 한 시간 내내 화면을 켜 둔다면 1~3만 건 정도입니다.
  **무료(Hobby) 플랜에는 월별 한도가 있으니** 대시보드의 Usage에서 사용량을 확인하세요. 부담되면 `POLL_SECONDS`를 늘리면 됩니다.
- **파일**: 브라우저가 Blob 저장소로 직접 올립니다(함수는 큰 파일을 받을 수 없습니다). 기본 한도는 파일 하나 50MB, 수업방 하나 200MB이고,
  전체 용량은 Blob 저장소의 한도를 따릅니다. 올릴 때 `vercel.com`, 받을 때 `*.public.blob.vercel-storage.com`에 접속하므로
  학교 네트워크에서 이 주소들이 막혀 있으면 파일 기능을 쓸 수 없습니다.
- **보관 기간**: 기본 14일(마지막 사용 기준). 지나면 수업방은 자동으로 사라지고, 남은 파일은 하루 한 번 도는 정리 작업이 지웁니다.
- **접속자 수**: 학생이 2분마다 보내는 신호로 세므로, 들어온 것은 10초 안에, 나간 것은 최대 몇 분 뒤에 반영됩니다.
- Vercel의 무료 플랜은 개인·비상업적 용도라는 조건이 있습니다. 학교 업무로 쓸 때는 약관을 확인하세요.

### 올리기 전에 내 컴퓨터에서 미리 보기

Vercel용 구성을 그대로(같은 함수, 같은 `vercel.json` 규칙) 내 컴퓨터에서 띄워 볼 수 있습니다. Redis와 Blob은 메모리로 흉내 내므로 끄면 내용이 사라집니다.

```bash
npm run dev:vercel
```

## 직접 서버로 실행하기

[Node.js](https://nodejs.org) 18 이상만 있으면 됩니다. 추가 설치(`npm install`)가 필요 없습니다.

```bash
node server.js
```

Windows에서는 `start.bat`을 더블클릭해도 됩니다. 실행하면 접속 주소가 표시됩니다.

```
  수업공유 서버가 시작되었습니다.

  이 컴퓨터에서       http://localhost:3000
  같은 네트워크에서   http://192.168.0.10:3000
```

브라우저에서 `http://localhost:3000`을 열고 **새 수업방 만들기**를 누르면 끝입니다.

### 교실 컴퓨터에서 바로 실행 (같은 Wi-Fi 안에서만)

선생님 컴퓨터에서 실행하고 `http://localhost:3000`으로 수업방을 만들면,
학생용 주소가 자동으로 이 컴퓨터의 내부망 주소(예: `192.168.0.10:3000/123456`)로 표시됩니다.

- 학생 기기가 **같은 네트워크**에 있어야 합니다.
- Windows는 처음 실행할 때 방화벽 허용 여부를 묻습니다. "허용"을 눌러야 학생 기기에서 접속됩니다.
- 학교 무선망이 기기끼리의 통신을 막아 둔 경우(단말 간 격리)에는 이 방법을 쓸 수 없습니다.
- 컴퓨터를 끄거나 절전 상태가 되면 서비스도 멈춥니다. 수업방과 파일은 `data/` 폴더에 남아 다시 켜면 이어집니다.

### 서버에 올려 두고 쓰기 (Docker)

Docker를 쓸 수 있는 곳이면 어디든 됩니다 — 클라우드 서버, 학교 서버, NAS 등.

```bash
docker compose up -d --build
```

`compose.yaml`에서 `TEACHER_PASSWORD`를 바꾸고, 주소가 정해지면 `PUBLIC_URL`을 적어 주세요.

- **프로세스 하나로 계속 떠 있어야 하고, 인스턴스는 1개만** 실행하세요. 접속 중인 학생 목록을 메모리에 두기 때문입니다.
- 데이터는 `DATA_DIR`(Docker에서는 `/data`)에 저장됩니다. 지속되는 디스크/볼륨에 연결하지 않으면 재배포할 때 수업방이 사라집니다.
- 주소의 최상위 경로에서 동작합니다 (`https://share.example.com/` ○, `https://example.com/share/` ×).
- 가능하면 **https**로 서비스하세요. http 주소에서도 동작하지만, 브라우저에 따라 파일을 받을 때 경고가 나올 수 있습니다.

nginx 뒤에 둘 때의 설정 예:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_buffering off;            # 실시간 전달
    proxy_request_buffering off;    # 큰 파일 올리기
    proxy_read_timeout 1h;
    client_max_body_size 100m;      # MAX_FILE_MB 와 같거나 크게
}
```

프록시 뒤에서는 `TRUST_PROXY=1`도 함께 설정하세요.

## 설정

모두 환경 변수이며, 지정하지 않으면 기본값을 씁니다.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `TEACHER_PASSWORD` | 없음 | 지정하면 수업방을 **만들 때** 이 비밀번호를 물어봅니다. 인터넷에 공개한다면 꼭 지정하세요. |
| `SITE_NAME` | `수업공유` | 화면에 표시되는 서비스 이름 |
| `MAX_FILE_MB` | 직접 서버 `100` / Vercel `50` | 파일 하나의 최대 크기 |
| `MAX_ROOM_MB` | 직접 서버 `500` / Vercel `200` | 수업방 하나에 올릴 수 있는 파일 합계 |
| `ROOM_TTL_DAYS` | 직접 서버 `30` / Vercel `14` | 마지막으로 쓴 뒤 이 기간이 지나면 수업방과 파일을 자동 삭제 |
| `PUBLIC_URL` | 없음 | 학생에게 보여 줄 주소 (예: `https://share.example.com`). 지정하지 않으면 접속한 주소를 그대로 씁니다. |

Vercel에서만 쓰는 것:

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `CRON_SECRET` | 없음 | 매일 도는 파일 정리 작업의 인증 값 (필수에 가깝습니다) |
| `POLL_SECONDS` | `3` | 학생 화면이 바뀐 내용을 확인하는 간격(초). 늘리면 요청 수가 줄고 반영이 늦어집니다. |
| `POLL_CACHE_SECONDS` | `2` | 위 확인의 답을 CDN이 보관하는 시간(초) |
| `PRESENCE_SECONDS` | `120` | 접속자 수 집계를 위해 학생 화면이 신호를 보내는 간격(초) |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN`, `BLOB_STORE_ID`(또는 `BLOB_READ_WRITE_TOKEN`) | — | 저장소를 연결하면 자동으로 들어옵니다 |

직접 서버로 실행할 때만 쓰는 것:

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | 모든 주소 | 특정 주소에서만 받으려면 지정 (예: `127.0.0.1`) |
| `DATA_DIR` | `./data` | 수업방과 파일을 저장할 폴더 |
| `MAX_TOTAL_MB` | `5000` | 서버 전체 파일 합계 |
| `MAX_ROOMS` | `500` | 수업방 최대 개수. 가득 차면 한 번도 쓰지 않은 오래된 빈 수업방부터 비웁니다. |
| `TRUST_PROXY` | `0` | 리버스 프록시 뒤에서 실행할 때 프록시 단계 수 (보통 `1`). 프록시 없이 직접 받는다면 `0`으로 두세요. |
| `ALLOW_FRAMING` | 꺼짐 | `1`이면 다른 사이트가 이 서비스를 iframe 안에 넣는 것을 허용 |

그 밖의 고정 한도: 글 하나 100KB, 수업방 하나의 글 합계 1MB, 수업방 하나의 항목 300개.

## 권한과 보안에 관해 알아 둘 점

- **수업방 주소(숫자 6자리)를 아는 사람은 누구나 내용을 볼 수 있습니다.** 성적, 개인정보처럼 민감한 자료는 올리지 마세요.
- **공유·삭제는 선생님만** 할 수 있습니다. 수업방을 만든 브라우저에 권한이 저장되며, 서버에는 권한 값의 해시만 남습니다.
  - 브라우저 데이터를 지우면 권한도 사라집니다. "선생님용 링크 복사"로 받은 링크를 즐겨찾기 등에 보관해 두세요.
  - 선생님용 링크는 비밀번호와 같습니다. 학생에게 보내지 마세요.
- 없는 코드를 계속 넣어 보는 시도는 같은 인터넷 주소(IP)에서 5분에 120번을 넘으면 잠시 차단됩니다.
  학교처럼 여러 사람이 인터넷 주소 하나를 함께 쓰는 곳에서는 한 사람 때문에 **새로 들어오려는** 사람이 몇 분간 막힐 수 있습니다.
  (이미 수업방을 연 화면과 선생님 화면은 영향받지 않습니다.)
- 올린 파일은 기본적으로 "다운로드"로 전달되고, 이미지·PDF·영상·텍스트만 브라우저에서 바로 열 수 있습니다.
  HTML·SVG처럼 스크립트를 담을 수 있는 파일은 이 사이트 안에서 실행되지 않습니다.
  (Vercel에서는 파일이 별도의 저장소 주소에서 제공됩니다.)
- 인터넷에 공개할 때는 `TEACHER_PASSWORD`를 지정하세요.

## 자주 겪는 문제

| 증상 | 확인할 것 |
| --- | --- |
| (Vercel) "서버 설정이 아직 끝나지 않았습니다" | Redis와 Blob 저장소를 프로젝트에 연결했는지, **연결한 뒤에 다시 배포했는지** (연결 전에 만든 배포에는 반영되지 않습니다) |
| (Vercel) 파일을 올리면 "파일 저장소에 접속하지 못했습니다" | Blob 저장소가 이 프로젝트(Production 환경)에 연결돼 있는지, 프로젝트 설정의 OIDC(Secure Backend Access)가 켜져 있는지 |
| (Vercel) 파일을 올리면 "비공개(Private)용이라 올릴 수 없습니다" | Blob 저장소를 **공개(Public)** 로 새로 만들어 연결하고 다시 배포 |
| (Vercel) 파일을 올리면 "파일 저장소가 받지 않았습니다" | 괄호 안에 저장소가 알려 준 이유가 표시됩니다. 저장소 용량 한도를 넘지 않았는지 확인하세요. |
| (Vercel) 파일만 안 올라가거나 안 받아진다 | 그 네트워크에서 `vercel.com`, `*.public.blob.vercel-storage.com` 접속이 되는지 |
| (Vercel) 공유한 내용이 늦게 보인다 | 정상 범위는 2~5초입니다. 더 늦다면 `POLL_SECONDS`, `POLL_CACHE_SECONDS` 값을 확인하세요. |
| (직접 서버) 학생 기기에서 주소가 열리지 않는다 | 같은 Wi-Fi인지, Windows 방화벽에서 Node.js를 허용했는지, 무선망의 단말 간 격리 여부 |
| (직접 서버) 접속 안내에 `localhost`가 나온다 | 이 컴퓨터의 IP 주소로 접속하거나 `PUBLIC_URL`을 지정하세요 (Docker로 실행했을 때 흔합니다). |
| (직접 서버) 큰 파일을 올리면 "프록시의 업로드 크기 제한" 오류 | 앞단 프록시의 제한입니다 (nginx는 `client_max_body_size`). |
| (직접 서버) 공유한 내용이 몇 초 늦게 보인다 | 중간 장비가 실시간 연결을 막는 네트워크입니다. 자동으로 몇 초 간격 확인 방식으로 바뀌어 동작합니다. |
| 상단에 계속 "연결 중…" | 서버가 꺼졌거나 네트워크가 끊긴 상태입니다. 다시 연결되면 자동으로 이어집니다. |

## 개발

```bash
npm test
```

Node.js 내장 테스트 도구를 씁니다. Vercel용 테스트 가운데 SDK(@vercel/blob)와 맞물리는 것들은 `npm install`을 한 뒤에만 실행되고, 아니면 건너뜁니다.

```
server.js                직접 서버 실행의 시작 지점
src/app.js               (직접 서버) HTTP 처리: 화면, API, 실시간 이벤트, 파일 올리기·내려받기
src/store.js             (직접 서버) 수업방·항목 저장 (data/rooms/*.json, data/files/)
src/hub.js               (직접 서버) 실시간 연결과 접속자 집계
src/ratelimit.js         (직접 서버) 접속 제한
src/config.js, util.js   공통 설정, 파일 이름 정리·링크 판별 등

api/index.js             (Vercel) 함수 진입점 — /api/* 를 모두 받음
src/vercel/handler.js    (Vercel) API 처리
src/vercel/rooms.js      (Vercel) 수업방·항목·접속자를 Redis에 저장
src/vercel/kv.js         (Vercel) Redis REST 호출
src/vercel/blob.js       (Vercel) 파일 저장소 연결 (@vercel/blob)
src/vercel/oidc.js       (Vercel) 저장소 접속에 쓰는 신원 토큰(OIDC) 꺼내기
vercel.json              (Vercel) 주소 규칙, 보안 머리글, 매일 도는 정리 작업
scripts/build-vercel.js  (Vercel) 정적 화면 빌드 → dist/
scripts/dev-vercel.js    Vercel용 구성을 내 컴퓨터에서 미리 보기

public/                  화면 (HTML · CSS · JavaScript). 두 방식이 같은 화면을 씁니다.
test/                    테스트와, 테스트용으로 흉내 낸 Redis·Blob (fake-blob-api.js 는 Blob의 관리 API를 흉내 냅니다)
```
